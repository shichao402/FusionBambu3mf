# ADR 0003：Fusion 与 3MF 各管一块

## 状态

已接受

## 背景

几何和参数定义在 Fusion 里。修改器类型、填充、工程配置和尺寸变体在 3MF 里。Fusion 不能还原打印配方。

## 决定

- 用组件路径对齐，例如 `底座/盖板/MOD 镂空`。
- 先有 Fusion 工程，再有 3MF。没有或丢失 3MF 时，从当前可见组件树新建空配方。
- 路径相同则导出时只换网格。新增节点需用户点「纳入」。消失的 part 留在文件里，本次导出不带它的网格。
- 在 Bambu 中改过的文件以重新打开后的解析结果为准。界面有未保存修改时先询问。
- 导出文件是派生结果，不回写源 3MF 的变体表。

## 后果

改名不会自动重新关联。丢了 3MF 就丢了打印配方和变体。
